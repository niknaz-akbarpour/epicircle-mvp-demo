# EpiCircle MVP Demo

**A research-stage digital health concept for connected seizure-event support, caregiver coordination, medication routines, and recovery follow-up.**

[View the public product website](https://epicircle-product.atieh-nowrouzi1972.chatgpt.site/) · [Open the interactive five-step demo](https://epicircle-product.atieh-nowrouzi1972.chatgpt.site/#demo)

## Project overview

EpiCircle explores how seizure-event communication can be organized as one closed-loop workflow rather than a collection of disconnected tools. The current version is a simulation-only interactive MVP designed for early feedback, portfolio review, and future stakeholder conversations.

The demo moves through five stages:

1. Baseline and signal-quality review
2. A suspected ongoing pattern
3. Human confirmation
4. Caregiver alert preparation and consent-based sample location
5. Recovery follow-up and structured review

## Current concept features

- Aura or observed-sign reporting
- Event timer and action-plan access
- Prioritized caregiver circle with acknowledgement status
- Consent-based location sharing
- Medication routine confirmation without dose-change recommendations
- Post-event recovery and reassurance checklist
- Bilingual English/Persian product presentation

## Safety boundaries

- This repository contains fictional and simulated information only.
- EpiCircle is **not a medical device** and does not diagnose epilepsy.
- The current demo does not detect real seizures, contact caregivers, call emergency services, or share real location.
- Medication decisions remain with a qualified prescribing clinician.
- Do not enter or commit real patient, emergency, identifying, or protected health information.

## Project status

EpiCircle is currently an early research and usability concept. Future development would require a clearly defined target event, consented multimodal data, clinical annotation, prospective validation, privacy and security controls, and an appropriate regulatory pathway.
